# 上下文与记忆管理

## 功能概述

管理发送给 Claude 的完整上下文：系统提示构建（多层拼接）、用户上下文（CLAUDE.md 指令文件）、Git 状态注入、对话历史压缩（auto-compact / micro-compact / reactive-compact）、Session Memory（自动提取对话要点）、附件与记忆检索。

---

## 从 main 函数入口的实现流程

### 1. 系统提示构建

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/constants/prompts.ts` | `getSystemPrompt(tools, model)` | 构建默认系统提示（工具说明、OS 信息、规则） |
| `src/utils/systemPrompt.ts` | `buildEffectiveSystemPrompt()` | 组装最终系统提示（多层优先级） |
| `src/utils/systemPromptType.ts` | `SystemPrompt` 类型 | 系统提示类型（字符串数组） |
| `src/utils/systemPromptType.ts` | `asSystemPrompt()` | 类型转换辅助 |

**系统提示优先级**（`buildEffectiveSystemPrompt` 中）：
1. Override → 完全覆盖（如有）
2. Coordinator 模式 → `getCoordinatorSystemPrompt()`
3. Agent 模式 → Agent 定义的 prompt
4. Custom 自定义 → 用户设置的 `systemPrompt`
5. Default → `getSystemPrompt()` 生成的默认提示
6. Append → `appendSystemPrompt` 追加内容

### 2. 上下文信息注入

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/context.ts` | `getSystemContext()` | 系统上下文（Git 状态、工作目录信息），memoized |
| `src/context.ts` | `getUserContext()` | 用户上下文（CLAUDE.md 内容、当前日期），memoized |
| `src/context.ts` | `getGitStatus()` | 获取 Git 状态信息 |
| `src/context.ts` | `getSystemPromptInjection()` / `setSystemPromptInjection()` | 动态注入系统提示 |
| `src/utils/api.ts` | `prependUserContext(messages, userContext)` | 将用户上下文前置到消息中 |
| `src/utils/api.ts` | `appendSystemContext(systemPrompt, systemContext)` | 将系统上下文追加到系统提示 |

### 3. CLAUDE.md 指令文件

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/utils/claudemd.ts` | `getClaudeMds()` | 加载所有 CLAUDE.md 文件 |
| `src/utils/claudemd.ts` | `getMemoryFiles()` | 获取记忆文件列表 |

**CLAUDE.md 加载顺序**（优先级从低到高）：
1. 企业托管 CLAUDE.md（managed）
2. 用户级 `~/CLAUDE.md`
3. 项目级 `CLAUDE.md` / `.claude/CLAUDE.md`
4. 项目级 `.claude/rules/*.md`（多文件规则）
5. 本地级覆盖

**`@include` 语法**：支持在 CLAUDE.md 中引用外部文件。

### 4. 对话历史压缩

#### 4.1 自动压缩 (Auto-Compact)

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/services/compact/autoCompact.ts` | `autoCompactIfNeeded()` | 在 token 接近上限时自动压缩 |
| `src/services/compact/autoCompact.ts` | `calculateTokenWarningState()` | 计算 token 警告状态 |
| `src/services/compact/autoCompact.ts` | `isAutoCompactEnabled()` | 是否启用自动压缩 |

#### 4.2 核心压缩

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/services/compact/compact.ts` | `compactConversation()` | 完整对话压缩（调用 Claude 生成摘要） |
| `src/services/compact/compact.ts` | `partialCompactConversation()` | 部分压缩（保留最近消息） |
| `src/services/compact/compact.ts` | `buildPostCompactMessages()` | 构建压缩后的消息数组 |
| `src/services/compact/compact.ts` | `createCompactCanUseTool()` | 为压缩创建受限权限函数 |

#### 4.3 微压缩 (Micro-Compact)

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/services/compact/microCompact.ts` | `microcompactMessages()` | 轻量级压缩：截断工具结果、压缩大输出 |

#### 4.4 其他压缩方式

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/services/compact/reactiveCompact.ts` | 响应式压缩 | prompt_too_long 错误时的紧急压缩（feature gated） |
| `src/services/compact/sessionMemoryCompact.ts` | 会话记忆压缩 | 结合 Session Memory 的压缩 |
| `src/services/compact/cachedMicrocompact.ts` | 缓存微压缩 | 带缓存的微压缩（feature gated） |
| `src/services/compact/apiMicrocompact.ts` | `getAPIContextManagement()` | API 级上下文管理 |

### 5. Session Memory（会话记忆）

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/services/SessionMemory/sessionMemory.ts` | 会话记忆模块 | 后台 forked agent 自动提取对话要点 |
| `src/services/SessionMemory/sessionMemoryUtils.ts` | 记忆工具函数 | 阈值配置、记忆格式化 |

**工作方式**：
1. 后台 forked agent 定期运行
2. 分析对话历史，提取关键信息
3. 生成 session memory markdown 文件
4. 后续对话中作为上下文附件注入

### 6. 附件与记忆检索

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/utils/attachments.ts` | `getAttachmentMessages()` | 获取附件消息（CLAUDE.md、记忆文件） |
| `src/utils/attachments.ts` | `startRelevantMemoryPrefetch()` | 预取相关记忆 |
| `src/utils/attachments.ts` | `createAttachmentMessage()` | 创建附件消息 |
| `src/utils/attachments.ts` | `filterDuplicateMemoryAttachments()` | 去重记忆附件 |
| `src/services/extractMemories/` | 记忆提取服务 | 从对话中提取持久记忆 |

### 7. 工具结果存储与压缩

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/utils/toolResultStorage.ts` | `applyToolResultBudget()` | 限制工具结果大小 |
| `src/utils/toolResultStorage.ts` | `ContentReplacementState` | 内容替换状态管理 |
| `src/utils/mcpOutputStorage.ts` | MCP 输出存储 | MCP 工具结果的存储管理 |

## 连接到 main.tsx 的流程

```
main.tsx
    │
    ├── 启动时预热:
    │     ├── void getSystemContext()     ← 预热 Git 状态缓存
    │     └── void getUserContext()       ← 预热 CLAUDE.md 缓存
    │
    ├── getSystemPrompt(tools, model)    ← 构建默认系统提示
    │
    └── REPL / query 运行时:
          │
          query.ts:queryLoop()
              │
              ├── 每次迭代开始:
              │     ├── startRelevantMemoryPrefetch()  ← 预取记忆
              │     ├── buildEffectiveSystemPrompt()   ← 组装系统提示
              │     ├── prependUserContext()            ← 注入用户上下文
              │     └── appendSystemContext()           ← 注入系统上下文
              │
              ├── API 调用前:
              │     ├── microcompactMessages()         ← 轻量压缩大输出
              │     └── token 预算检查
              │
              ├── API 调用后:
              │     └── autoCompactIfNeeded()          ← 自动压缩检测
              │           └── compactConversation()    ← 完整压缩
              │                 ├── 调用 Claude 生成摘要
              │                 ├── buildPostCompactMessages()
              │                 └── continue → 下一次迭代
              │
              └── 后台:
                    └── Session Memory agent           ← 定期提取要点
```
