# 认证与授权系统

## 功能概述

支持三种认证方式：Anthropic API Key（直连）、OAuth（Claude AI 订阅登录）、云服务商凭证（AWS Bedrock / GCP Vertex / Azure Foundry）。包含安全存储（macOS Keychain + 明文回退）、信任对话框（项目级信任确认）、令牌刷新与多租户组织验证。

---

## 从 main 函数入口的实现流程

| `src/utils/secureStorage/keychainPrefetch.ts` | `getLegacyApiKeyPrefetchResult()` | 获取预取的传统 API Key |

### 2. 安全存储层

### 5. 云服务商认证

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/services/api/client.ts` | `getAnthropicClient()` | 根据 provider 创建对应 SDK 客户端 |
| `src/utils/auth.ts` | `refreshAndGetAwsCredentials()` | 刷新并获取 AWS 凭证 |
| `src/utils/auth.ts` | `refreshGcpCredentialsIfNeeded()` | 刷新 GCP 凭证 |
| `src/utils/auth.ts` | `prefetchAwsCredentialsAndBedRockInfoIfSafe()` | 安全预取 AWS 凭证 |
| `src/utils/auth.ts` | `prefetchGcpCredentialsIfSafe()` | 安全预取 GCP 凭证 |
| `src/utils/auth.ts` | `clearAwsCredentialsCache()` | 清除 AWS 凭证缓存 |
| `src/utils/model/providers.ts` | `getAPIProvider()` | 判断当前 API 提供商 (firstParty/bedrock/vertex/foundry) |

**Provider 选择逻辑**（在 `getAnthropicClient()` 中）：

| 环境变量 / 条件 | Provider | SDK 类 |
|----------------|----------|--------|
| `ANTHROPIC_API_KEY` / `ANTHROPIC_AUTH_TOKEN` | Direct API | `Anthropic` |
| AWS 环境 + Bedrock 配置 | AWS Bedrock | `AnthropicBedrock` |
| `ANTHROPIC_VERTEX_PROJECT_ID` | GCP Vertex AI | `AnthropicVertex` |
| `ANTHROPIC_FOUNDRY_RESOURCE` | Azure Foundry | `Anthropic` (自定义 baseURL) |

### 6. 信任对话框

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/components/TrustDialog/TrustDialog.tsx` | `TrustDialog` | 信任确认 UI 组件 |
| `src/utils/config.ts` | `checkHasTrustDialogAccepted()` | 检查当前项目是否已接受信任 |
| `src/utils/config.ts` | `isPathTrusted()` | 检查路径是否在信任范围内 |
| `src/interactiveHelpers.tsx` | `showSetupScreens()` | 显示信任对话框 + Onboarding |

**信任流程**：
1. 交互模式启动时，`showSetupScreens()` 检查 `checkHasTrustDialogAccepted()`
2. 未信任 → 显示 `TrustDialog` 组件，用户确认后 `saveCurrentProjectConfig()` 持久化
3. 信任后 → `applyConfigEnvironmentVariables()` 应用完整环境变量（含项目级 settings）

## 连接到 main.tsx 的时序

```
main.tsx 模块加载
    ├── startKeychainPrefetch()          ← 并行预取 OAuth/API Key

preAction 钩子
    ├── ensureKeychainPrefetchCompleted() ← 等待预取完成
    └── init()
          └── populateOAuthAccountInfoIfNeeded()  ← 补全 OAuth 信息

action 处理器
    ├── validateForceLoginOrg()           ← 组织验证
    ├── prefetchAwsCredentialsAndBedRockInfoIfSafe()  ← AWS 预取
    ├── prefetchGcpCredentialsIfSafe()    ← GCP 预取
    ├── showSetupScreens()               ← TrustDialog
    │     └── applyConfigEnvironmentVariables()  ← 信任后应用完整环境变量
    └── launchRepl()

API 调用时（运行时）
    └── getAnthropicClient()             ← 按 provider 创建 SDK 客户端
          ├── Direct → new Anthropic(...)
          ├── Bedrock → new AnthropicBedrock(...)
          ├── Vertex → new AnthropicVertex(...)
          └── Foundry → Anthropic + Azure endpoint
```
