# 配置管理系统

## 功能概述

多层配置合并体系：用户级（`~/.claude/settings.json`）、项目级（`.claude/settings.json`）、本地级、CLI 参数（`--settings`）、企业策略（MDM/远程托管）、插件设置。后源覆盖前源。还包括全局配置（`~/.claude.json`）和项目配置。支持环境变量注入、配置变更监听。

---

## 从 main 函数入口的实现流程

### 1. Settings 层级系统

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/utils/settings/constants.ts` | `SETTING_SOURCES` | 定义配置源优先级顺序 |
| `src/utils/settings/settings.ts` | `getInitialSettings()` | 获取合并后的初始设置快照 |
| `src/utils/settings/settings.ts` | `getSettings_DEPRECATED()` | 获取设置（已废弃接口） |
| `src/utils/settings/settings.ts` | `getSettingsWithErrors()` | 获取设置并附带错误信息 |
| `src/utils/settings/settings.ts` | `loadSettingsFromDisk()` | 从磁盘加载所有配置源并合并 |

**配置源优先级**（低 → 高，后者覆盖前者）：

| 优先级 | 源名称 | 路径 / 来源 |
|-------|--------|-----------|
| 0 | 插件设置 | `getPluginSettingsBase()` |
| 1 | `userSettings` | `~/.claude/settings.json` |
| 2 | `projectSettings` | `.claude/settings.json`（项目根） |
| 3 | `localSettings` | `.claude/settings.local.json`（不提交到 Git） |
| 4 | `flagSettings` | `--settings` CLI 参数 / SDK 内联 JSON |
| 5 | `policySettings` | 企业策略（远程托管 > MDM > 本地策略文件） |

### 2. 全局配置

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/utils/config.ts` | `getGlobalConfig()` | 读取 `~/.claude.json`（用户偏好：主题、vim、编辑器等） |
| `src/utils/config.ts` | `saveGlobalConfig()` | 保存全局配置 |
| `src/utils/config.ts` | `enableConfigs()` | 验证并启用配置系统 |
| `src/utils/config.ts` | `checkHasTrustDialogAccepted()` | 检查信任对话框是否已接受 |
| `src/utils/config.ts` | `isPathTrusted()` | 检查路径信任状态 |
| `src/utils/config.ts` | `getRemoteControlAtStartup()` | 获取远程控制启动配置 |
| `src/utils/config.ts` | `isAutoUpdaterDisabled()` | 是否禁用自动更新 |
| `src/utils/config.ts` | `recordFirstStartTime()` | 记录首次启动时间 |

### 3. 项目配置

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/utils/config.ts` | `getCurrentProjectConfig()` | 获取当前项目配置 |
| `src/utils/config.ts` | `saveCurrentProjectConfig()` | 保存项目配置 |

**项目配置内容**：MCP 服务器、信任标志、Worktree 会话、MCP 启用/禁用列表。

### 4. 环境变量管理

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/utils/managedEnv.ts` | `applySafeConfigEnvironmentVariables()` | 信任前：仅应用安全环境变量 |
| `src/utils/managedEnv.ts` | `applyConfigEnvironmentVariables()` | 信任后：应用完整 `settings.env` 到 `process.env` |

**安全环境变量**（信任前可应用）：
- `ANTHROPIC_API_KEY`、`ANTHROPIC_BASE_URL`、`ANTHROPIC_AUTH_TOKEN`
- 来源限制：仅 `userSettings`、`flagSettings`、`policySettings`

**完整环境变量**（信任后应用）：
- 所有 `settings.env` 中定义的变量
- 包括项目级和本地级的变量
- 代理重配置、缓存清理

### 5. MDM（设备管理）策略

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/utils/settings/mdm/rawRead.ts` | `startMdmRawRead()` | 启动 MDM 子进程读取（并行）|
| `src/utils/settings/mdm/` | MDM 读取模块 | macOS `plutil` / Windows 注册表查询 |

### 6. 远程托管设置

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/services/remoteManagedSettings/index.ts` | `loadRemoteManagedSettings()` | 加载远程托管设置 |
| `src/services/remoteManagedSettings/index.ts` | `refreshRemoteManagedSettings()` | 刷新远程设置 |
| `src/services/remoteManagedSettings/index.ts` | `isEligibleForRemoteManagedSettings()` | 是否符合远程设置条件 |

### 7. 策略限制

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/services/policyLimits/index.ts` | `loadPolicyLimits()` | 加载策略限制 |
| `src/services/policyLimits/index.ts` | `isPolicyAllowed(feature)` | 检查功能是否被策略允许 |
| `src/services/policyLimits/index.ts` | `waitForPolicyLimitsToLoad()` | 等待策略加载完成 |
| `src/services/policyLimits/index.ts` | `refreshPolicyLimits()` | 刷新策略 |

### 8. 配置变更监听

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/utils/settings/changeDetector.ts` | `settingsChangeDetector` | 监听 settings 文件变更 |
| `src/utils/skills/skillChangeDetector.ts` | `skillChangeDetector` | 监听 Skills 文件变更 |

## 连接到 main.tsx 的流程

```
main.tsx 模块加载
    │
    ├── startMdmRawRead()            ← 并行启动 MDM 读取子进程
    │
    preAction 钩子
    │     └── init()
    │           ├── enableConfigs()   ← 验证并启用配置系统
    │           ├── applySafeConfigEnvironmentVariables()
    │           │     ├── 读取 globalConfig.env
    │           │     ├── 读取 userSettings.env (安全变量)
    │           │     ├── 读取 flagSettings.env (--settings)
    │           │     └── 读取 policySettings.env
    │           └── ...
    │
    action 处理器
    │
    ├── --settings 解析 → flagSettings
    │
    ├── 策略加载:
    │     ├── loadRemoteManagedSettings()
    │     ├── loadPolicyLimits()
    │     └── waitForPolicyLimitsToLoad()
    │
    ├── showSetupScreens() → TrustDialog
    │     └── 信任后:
    │           └── applyConfigEnvironmentVariables()
    │                 ├── 合并所有 settings.env
    │                 ├── 写入 process.env
    │                 ├── 清除凭证缓存
    │                 └── 重配置代理
    │
    ├── getInitialSettings()  ← 用于遥测和会话配置
    │
    └── REPL 运行中:
          ├── settingsChangeDetector     ← 监听文件变更
          ├── skillChangeDetector        ← 监听 Skills 变更
          └── refreshRemoteManagedSettings()  ← 定期刷新远程设置
```
