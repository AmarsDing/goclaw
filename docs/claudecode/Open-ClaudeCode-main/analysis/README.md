## 项目总体架构

Claude Code 是一个 **AI 驱动的终端编程助手**，核心架构为：

```
React (Ink) 终端 UI  +  Anthropic SDK  +  MCP 工具协议  +  插件系统
                    ↓
        「用户输入 → LLM 推理 → 工具执行 → 结果反馈」Agent Loop
```

项目划分为 **14 大功能模块**，每个模块有独立的分析文档：
