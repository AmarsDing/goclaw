# 会话管理与历史

## 功能概述

管理对话会话的完整生命周期：创建、持久化、恢复、搜索、导出。包括消息 transcript 存储、REPL 命令行历史、会话状态通知、背景会话管理、cost 追踪。支持 `--continue`（继续最近对话）和 `--resume`（恢复指定会话）。

**恢复流程**（`--continue` / `--resume`）：
1. `main.tsx` 检查 `-c`（最近对话）或 `-r <session-id>`（指定会话）
2. `loadTranscriptFromFile()` 从 `~/.claude/sessions/` 加载 transcript
3. `processResumedConversation()` 重建消息数组和上下文
4. 将恢复的消息传入 REPL

## 连接到 main.tsx 的流程

```
main.tsx
    │
    ├── 会话 ID 生成 (bootstrap/state.ts → getSessionId())
    │
    ├── --continue (-c):
    │     └── 查找最近会话 → loadTranscriptFromFile()
    │           → processResumedConversation()
    │           → 恢复消息传入 REPL
    │
    ├── --resume (-r <id>):
    │     └── sessionIdExists(id) → loadTranscriptFromFile()
    │           → processResumedConversation()
    │           → 恢复消息传入 REPL
    │
    ├── --session-id / --name:
    │     └── searchSessionsByCustomTitle()
    │
    ├── 正常启动:
    │     └── 新建空会话 → messages = []
    │
    └── REPL 运行中:
          ├── addToHistory(input)     ← 每次用户输入
          ├── recordTranscript()      ← 每条消息持久化
          ├── getTotalCost()          ← 费用追踪
          └── notifySessionStateChanged()  ← 状态通知
```
