# 插件系统 (Plugins)

## 功能概述

支持多种插件来源：内置注册（built-in）、Marketplace 安装、`--plugin-dir` 命令行加载、项目级配置。插件可提供：Skills（斜杠命令）、Hooks（生命周期钩子）、MCP 服务器、Agents 定义、自定义设置。与 Skills 系统互补但层次更高。

---

## 从 main 函数入口的实现流程

### 1. 内置插件注册

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/plugins/builtinPlugins.ts` | `registerBuiltinPlugin()` | 注册内置插件到全局注册表 |
| `src/plugins/builtinPlugins.ts` | `getBuiltinPlugins()` | 返回所有内置插件（受 `enabledPlugins` 设置控制） |
| `src/plugins/builtinPlugins.ts` | `getBuiltinPluginSkillCommands()` | 获取内置插件的 Skill 命令 |
| `src/plugins/builtinPlugins.ts` | `isBuiltinPluginId()` | 判断是否为内置插件 ID |
| `src/plugins/bundled/index.ts` | `initBuiltinPlugins()` | 在 main.tsx 中调用，注册所有内置插件 |

### 2. 插件加载器

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/utils/plugins/pluginLoader.ts` | 插件发现与加载 | Marketplace、`--plugin-dir`、项目配置 |
| `src/utils/plugins/pluginLoader.ts` | `loadAllPluginsCacheOnly()` | 从缓存加载所有插件（不触发网络） |
| `src/utils/plugins/pluginLoader.ts` | `setInlinePlugins()` | 设置 `--plugin-dir` 指定的内联插件 |
| `src/utils/plugins/schemas.ts` | 插件 Schema | `plugin.json` 的 Zod 验证 Schema |
| `src/utils/plugins/mcpbHandler.ts` | MCP 桥接处理 | 插件 MCP 服务器的安全处理 |

**插件目录结构**（标准格式）：
```
plugin-name/
├── .claude-plugin/
│   └── plugin.json          ← 元数据（name, description, version, author）
├── commands/                ← Skill 命令（markdown 文件）
│   └── my-skill.md
├── agents/                  ← Agent 定义
├── hooks/                   ← 生命周期钩子
└── settings/                ← 插件设置
```

### 3. 插件操作（安装/卸载/启用）

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/services/plugins/pluginOperations.ts` | `installPluginOp()` | 安装插件（按 scope） |
| `src/services/plugins/pluginOperations.ts` | `uninstallPluginOp()` | 卸载插件 |
| `src/services/plugins/pluginOperations.ts` | `setPluginEnabledOp()` | 启用/禁用插件 |
| `src/services/plugins/pluginCliCommands.ts` | `installPlugin()` | CLI 层安装入口 |
| `src/services/plugins/pluginCliCommands.ts` | `uninstallPlugin()` | CLI 层卸载入口 |
| `src/services/plugins/pluginCliCommands.ts` | `VALID_INSTALLABLE_SCOPES` | 有效安装范围：`user` / `project` / `local` |
| `src/services/plugins/PluginInstallationManager.ts` | `performBackgroundPluginInstallations()` | 后台异步安装 |

### 5. 插件与 Skills 的区别

| 维度 | 插件 (Plugins) | Skills (Bundled) |
|------|---------------|------------------|
| 分发方式 | Marketplace / git / `--plugin-dir` / 内置注册 | 编译到 CLI 二进制中 |
| 切换控制 | 用户通过 `enabledPlugins` 设置，`/plugin` 命令 | 功能门控 / 每 Skill `isEnabled` |
| 包含内容 | Manifest + commands/ + agents/ + hooks/ + MCP 服务器 + settings | 单个 Prompt 命令 + 可选 hooks |
| UI 管理 | `/plugin` 命令 + Marketplace UI | `/skills` 命令 |
| 配置合并 | 插件 settings 作为最低优先级合并到全局 settings | 无独立 settings |

## 连接到 main.tsx 的流程

```
main.tsx action 处理器
    │
    ├── initBuiltinPlugins()         ← src/plugins/bundled/index.ts
    │     └── registerBuiltinPlugin() × N
    │
    ├── (--plugin-dir) → clearPluginCache() → setInlinePlugins()
    │
    ├── initializeVersionedPlugins() ← 后台版本管理
    │
    ├── getCommands(cwd)             ← src/commands.ts
    │     └── loadAllCommands()
    │           ├── getBuiltinPluginSkillCommands()  ← 内置插件 Skills
    │           ├── loadAllPluginsCacheOnly()         ← 已安装插件
    │           └── 合并到命令列表
    │
    ├── getClaudeCodeMcpConfigs()    ← src/services/mcp/config.ts
    │     └── getPluginMcpServers()  ← 插件提供的 MCP 服务器
    │
    └── settings 合并
          └── getPluginSettingsBase()  ← 插件 settings（最低优先级）
```
