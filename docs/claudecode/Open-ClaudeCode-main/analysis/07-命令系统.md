# 命令系统 (Slash Commands)

## 功能概述

100+ 内置斜杠命令，用户在交互模式下输入 `/` 前缀触发。命令分三种类型：`prompt`（注入模型提示）、`local`（本地执行返回结果）、`local-jsx`（渲染 React 组件）。命令来源包括内置、插件、Skills、工作流。

---

## 从 main 函数入口的实现流程

### 1. 命令注册

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/commands.ts` | `getCommands(cwd)` | 异步合并所有命令源：内置 + 插件 + Skills + 工作流 |
| `src/commands.ts` | `COMMANDS()` | 返回内置命令数组（memoized） |
| `src/commands.ts` | `loadAllCommands(cwd)` | 加载全部命令（含动态 Skills） |
| `src/commands.ts` | `findCommand()` / `getCommand()` | 按名称查找命令 |
| `src/commands.ts` | `filterCommandsForRemoteMode()` | 远程模式命令过滤 |
| `src/types/command.ts` | `Command` 联合类型 | `PromptCommand` / `LocalCommand` / `LocalJSXCommand` |

**注册流程**：`main.tsx` → `getCommands(cwd)` → 合并内置 `COMMANDS()` + 插件命令 + Skill 命令 + 工作流 → 过滤 `isCommandEnabled` → 传入 REPL。

### 2. 命令类型

| 类型 | `type` 值 | 执行方式 | 示例 |
|------|----------|---------|------|
| Prompt 命令 | `'prompt'` | `getPromptForCommand()` 返回内容注入到模型 | `/commit`, `/review` |
| Local 命令 | `'local'` | `call()` 本地执行返回结构化结果 | `/clear`, `/compact`, `/cost` |
| Local JSX 命令 | `'local-jsx'` | `call(onDone)` 渲染 React/Ink UI | `/help`, `/model`, `/theme` |

### 4. 命令执行流程

命令在 `processUserInput()` 中被路由：

| 文件路径 | 关键函数 | 职责 |
|---------|---------|------|
| `src/utils/processUserInput/processUserInput.ts` | `processUserInput()` | 检测 `/` 前缀 → 查找命令 → 分发 |
| `src/utils/slashCommandParsing.ts` | 命令解析辅助 | 解析命令名和参数 |

```
用户输入 "/compact"
    │
    ▼
processUserInput()
    ├── 检测 "/" 前缀
    ├── findCommand("compact")       ← src/commands.ts
    ├── 检查 isCommandEnabled()
    └── 根据 type 分发:
          ├── 'prompt' → getPromptForCommand() → 注入消息 → query()
          ├── 'local'  → load() → call() → 返回结果
          └── 'local-jsx' → load() → call(onDone) → 渲染 UI
```
